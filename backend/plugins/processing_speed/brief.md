Processing speed is measured only by timed blocks of many easy trials. You write a symbol key or
a stimulus-to-response mapping, the instruction text and the trial rule. You never write
questions or prose items, and you never hide the key. If you find yourself writing a question
for this domain, something has gone wrong.

## Written questions (single items, always time-limited)

- **code_match** — stem is one code (capital letters without I/O, digits 2–9); instruction "Find the exact
  copy of this code."; exactly one option copies it character for character, the others swap two
  neighbouring characters or change one character.
- **quick_arithmetic** — stem "a + b = ?" / "a − b = ?" / "a × b = ?" sized by `arithmetic_operation`;
  instruction "Choose the answer as quickly as you can."; options are close whole numbers, one correct.
