Recognition items are built in three phases: encode, delay, retrieve. Encoding is always announced
before it starts, and every stimulus is clearly visible for the full exposure time. During
retrieval, each probe shows options only: never restate what was encoded. Visual items use
objects from the asset registry by id (for example "g1:arrow:solid:90"); never invent pictures,
image URLs or descriptions of images. Foils are chosen by similarity class from the registry or
the lexicon, so that a foil is wrong only because it was not shown.
